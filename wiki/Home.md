# Cadence Wiki

Welcome to the official **Cadence** documentation!

Cadence is an all-in-one Discord music bot and real-time YouTube Music style web dashboard built with TypeScript, Bun, Hono, React 19, Tailwind CSS v4, `discord.js` v14, `lavalink-client`, and `bun:sqlite`.

## Documentation Pages

- [Installation and Deployment](Installation-and-Deployment) - Docker Compose (GHCR images), bare-metal Bun setup, and reverse proxy configuration
- [Discord Bot Setup](Discord-Bot-Setup) - Discord Developer Portal intents, OAuth2 Redirect URIs, and the 4-step Web Onboarding Wizard
- [Commands and Shortcuts](Commands-and-Shortcuts) - All 23 Discord slash commands, customizable prefix commands, and web keyboard shortcuts
- [Role-Based Access Control](Role-Based-Access-Control) - How Cadence's 4-tier cascading Discord permission model works
- [Playback and Empty VC](Playback-and-Empty-VC) - Timeline queue, drag-and-drop, queue loop, Smart Autoplay moods, and empty voice channel auto-pause/resume/disconnect
- [Troubleshooting](Troubleshooting) - Slash command syncing, Lavalink YouTube client order, OAuth2 errors, and SQLite backups
