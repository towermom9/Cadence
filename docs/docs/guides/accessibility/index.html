Accessibility

Inclusive visual, keyboard, touch, and assistive-technology controls modeled after Material 3 adaptive clarity and W3C Web Accessibility Initiative (WCAG 2.2 POUR) standards.

Accessibility Settings Tab

Open Settings -> Accessibility in the web dashboard to customize these per-user options:

  • High Contrast Mode: Strengthens borders, muted labels, and card edge legibility across dark and AMOLED surfaces.
  • Reduce Motion: Disables hover zoom transitions and animations across cards and drawers (also respects operating system reduced-motion settings).
  • Text Size Scale (90% - 130%): Scales base typography smoothly without breaking dashboard layouts.
  • Enhanced Keyboard Focus Rings: Displays crisp 3px accent outlines on focused buttons, sliders, switches, and links alongside the top-left Skip to main content landmark jump link.
  • Larger Interactive Touch Targets: Enforces Material 3 44x44px minimum touch target dimensions on interactive controls.
  • Long-Press Detector Delay (200ms - 1200ms): Lets touch users customize the hold duration before opening the queue track action menu (supports both sliding and direct numeric typing).
  • Screen Reader Track Announcements: Broadcasts active track changes and pause/resume transitions using a polite aria-live="polite" region without interrupting focus.

Custom Colors & Contrast Verification

Under Settings -> Appearance -> Background Surface, open Advanced · Custom Colors to pick custom hex colors for Accent Hex, Canvas Background, and Card Surface. The color picker previews live via requestAnimationFrame and shows a real-time WCAG AA Contrast Ratio badge comparing accent foregrounds against your background canvas.

Typeable Sliders & Mobile Ergonomics

  • Typeable Sliders: Every settings slider pairs the visual range track with an inline numeric input box so users can type exact values directly using keyboard navigation instead of dragging with a pointer.
  • Mobile & Touch Queue Reordering: In the Now Playing queue timeline, touch users can drag the grip handle smoothly using Pointer Events or tap the inline up/down arrows, while keyboard shortcut hints automatically hide on phones and stay visible on desktops and tablets.
