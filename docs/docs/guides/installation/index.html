Installation & Deployment

Run Cadence in production via Docker Compose or develop locally with Bun and Vite HMR.

Audio & App Stack

  • cadence - Discord bot, Hono HTTP/OAuth2 + WebSocket server, React 19 UI, and bun:sqlite.
  • lavalink - Self-contained Lavalink v4 image (ghcr.io/towermom9/cadence-lavalink:latest) with pre-bundled youtube-plugin, lavasrc-plugin, and lavalyrics-plugin.
  • yt-cipher - YouTube signature cipher helper for Lavalink.
  • spotify-tokener - Anonymous Spotify token service for LavaSrc metadata resolution.

Option 1: Pre-Built GHCR Docker Compose

Ideal for VPS hosts, Portainer, Dokploy, or Coolify with zero repository clone or host plugin mounts:

name: cadence

services:
  cadence:
    container_name: cadence
    image: ghcr.io/towermom9/cadence:latest
    restart: unless-stopped
    env_file:
      - path: .env
        required: false
    environment:
      - LAVALINK_HOST=lavalink
      - LAVALINK_PORT=2333
      - LAVALINK_PASSWORD=${LAVALINK_PASSWORD:-youshallnotpass}
      - DATA_DIR=/app/data
    ports:
      - "8686:8000"
    volumes:
      - ./data:/app/data
    networks:
      - cadence
    depends_on:
      lavalink:
        condition: service_started

  lavalink:
    container_name: cadence-lavalink
    image: ghcr.io/towermom9/cadence-lavalink:latest
    restart: unless-stopped
    environment:
      - _JAVA_OPTIONS=-Xmx1G
      - SERVER_PORT=2333
      - LAVALINK_SERVER_PASSWORD=${LAVALINK_PASSWORD:-youshallnotpass}
      - YT_CIPHER_URL=http://yt-cipher:8001
      - SPOTIFY_TOKEN_ENDPOINT=http://spotify-tokener:49152/api/token
    expose:
      - "2333"
    networks:
      - cadence
    depends_on:
      - yt-cipher
      - spotify-tokener

  yt-cipher:
    container_name: cadence-yt-cipher
    image: ghcr.io/kikkia/yt-cipher:master
    restart: unless-stopped
    expose:
      - "8001"
    networks:
      - cadence

  spotify-tokener:
    container_name: cadence-spotify-tokener
    image: ghcr.io/topi314/spotify-tokener:master
    restart: unless-stopped
    environment:
      - SPOTIFY_TOKENER_ADDR=0.0.0.0:49152
    expose:
      - "49152"
    networks:
      - cadence

networks:
  cadence:
    name: cadence

Option 2: Local Bare-Metal Development

bun install
docker compose up -d lavalink yt-cipher spotify-tokener

# Terminal 1: Backend & Discord bot (:8000)
bun run dev

# Terminal 2: Vite HMR frontend (:5173)
bun run dev:web

Reverse Proxy & HTTPS

  • Forward both HTTP traffic (/, /api/*) and WebSocket upgrades (/ws) to port 8000 (or your mapped host port).
  • When exposing Cadence under a custom domain (e.g. https://music.example.com), update the domain directly in Settings -> System -> Public Domain & Dashboard URL or set DASHBOARD_URL in .env so OAuth2 redirects, secure session cookies, and Discord controller links match.
