Playback, Queue Timeline & Empty VC

Understand Cadence's continuous queue timeline, automatic voice channel switching, Queue Loop deduplication, and empty VC automation.

Timeline Queue Model

Every server queue is presented as a single continuous timeline with four sections:

  1. Previous - Unlimited played track history above the current track.
  2. Current - The active track currently playing in Lavalink.
  3. Manual Queue - Tracks queued by users (/play, /playnext, /playnow, search, or playlists).
  4. Autoplay - Dynamic recommendations appended below the manual queue when Autoplay is active.

Dragging the active song reorders the surrounding tracks cleanly without restarting or cutting audio. Manual/history tracks and Autoplay tracks stay separated across the Autoplay boundary.

Automatic Server Selection on Voice Join

Whenever you join or hop into a voice channel on Discord while logged into the dashboard, Cadence automatically detects your active voice channel server and switches the dashboard's active Play on Server target to match - so hitting Play in the web UI starts music in the exact server you are sitting in.

Queue Loop & Smart Autoplay

  • Queue Loop (repeatMode = queue): Loops strictly across your manual queue and played history while ignoring Autoplay suggestions. Wrapped tracks skip duplicate play-history entries so looped playlists never spam your History tab.
  • 7 Autoplay Moods: Choose between All, Familiar, Discover, Popular, Deep Cuts, Chill, and Upbeat, and customize what happens when you click an Autoplay song in Settings -> Playback.

Empty Voice Channel Auto-Pause, Resume & Disconnect

Configure these per-server options under Settings -> Server (auto-saved immediately) or /settings emptyvc:

  • Pause When Voice Channel is Empty: Pauses playback when no active listeners remain in the bot's voice channel and posts a styled Music Controller notice in Discord chat.
  • Continue Playing Delay (0s - 5m): Wait before pausing so brief reconnects do not interrupt music.
  • Auto-Disconnect After Extended Auto-Pause (Never, 5m - 2h): Leaves voice if nobody joins back after extended auto-pause (automatically disabled while 24/7 Mode is on).
  • Ignore Deafened Listeners: Treat self-deafened or server-deafened members as not listening when checking if the channel is empty.
Respects Manual Pauses
If a DJ paused playback manually while listeners were present, someone joining later will not force-resume the manual pause.
