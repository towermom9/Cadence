Internationalization & Localization

How Cadence separates translatable interface strings from application logic, detects browser languages with BCP 47 standards, and maintains multi-language catalogs.

BCP 47 Language Tags & Browser Detection

Cadence follows the IETF BCP 47 standard for identifying languages cleanly:

  • Selecting System Default (Auto) under Settings -> Appearance -> Language reads your browser's primary language subtag (e.g., ja-JP resolves to ja) and falls back cleanly to English (en).
  • The active resolved language updates <html lang="..."> automatically so screen readers, spellcheckers, and font fallback engines render each script accurately.
  • Message interpolation uses named ICU-style {placeholder} tokens so translators can adjust word order naturally across languages.
