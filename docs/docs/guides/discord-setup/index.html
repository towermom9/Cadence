Discord Bot Setup

Configure your Discord Developer Portal application, privileged Gateway intents, and OAuth2 redirect URLs.

1. Create a Discord Application

  1. Open the Discord Developer Portal and create a new application.
  2. Navigate to Bot and click Reset Token to obtain your Bot Token.
  3. Under Privileged Gateway Intents, enable:
    • Server Members Intent (required for role lookups and tier permissions)
    • Message Content Intent (required for text prefix commands such as ?play and ?playnext)

2. Configure OAuth2 Redirects

  1. Navigate to OAuth2 -> General.
  2. Copy your Client ID and Client Secret.
  3. Under Redirects, add your exact callback URL:
    • Local dev: http://localhost:8000/api/auth/callback
    • Docker / custom domain: https://your-domain.example/api/auth/callback
Exact Match Required
Discord requires the redirect URL in Developer Portal to match your live Cadence Domain / Dashboard URL character-for-character (protocol, hostname, port, and /api/auth/callback path).

3. Web Onboarding Wizard

On first boot without .env credentials, Cadence serves a 4-step Web Onboarding Wizard that:

  1. Verifies Lavalink connectivity (and optional SETUP_TOKEN).
  2. Tests your Discord Bot Token and confirms privileged intents are active.
  3. Saves your OAuth2 credentials and public Dashboard URL.
  4. Generates a bot invite link with voice and slash-command permissions.

4. Refreshing Slash Commands

Cadence syncs all 23 global slash commands automatically on login. If you just updated Cadence and a new command like /playnext has not appeared yet in Discord, press Ctrl + R (Cmd + R on macOS) in your Discord client after restarting the bot container.
