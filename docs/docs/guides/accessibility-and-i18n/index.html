Accessibility, Custom Colors & i18n

Design principles, WCAG 2.2 accessibility controls, custom hex theme swatches, typeable sliders, and BCP 47 localization across the Cadence dashboard.

Accessibility (Material 3 + W3C WAI / WCAG 2.2)

Cadence's Settings -> Accessibility tab is designed around Material 3 adaptive clarity and W3C WAI / WCAG 2.2 POUR principles (Perceivable, Operable, Understandable, Robust):

  • High Contrast Mode (data-contrast="high"): Increases card border contrast, muted label brightness, and control outlines for easier reading.
  • Reduce Motion (data-motion="reduced"): Disables artwork zoom effects, hover animations, and smooth transitions (alongside OS prefers-reduced-motion).
  • Text Size Scale (90% - 130%): Adjusts root typography smoothly without clipping cards or breaking responsive grids.
  • Enhanced Keyboard Focus Rings (data-focus="enhanced"): Renders crisp 3px accent rings on keyboard-focused buttons, sliders, switches, and links, paired with a top-left Skip to main content landmark link.
  • Larger Interactive Touch Targets (data-touch="large"): Enforces Material 3 44x44px minimum touch areas on controls.
  • Screen Reader Track Announcements: Uses a polite aria-live="polite" region to announce active tracks and play/pause transitions without stealing focus.

Custom Colors & Typeable Sliders

  • Advanced · Custom Colors: Under Settings -> Appearance, pick custom 6-digit hex swatches for Accent Hex, Canvas Background, and Card Surface with live WCAG AA contrast ratio calculation.
  • Direct Numeric Input on Every Slider: All dashboard sliders (volume, seek interval, text scale, default volume, max history, empty VC delays, and stuck-track timeout) pair the range track with an inline typeable number box.

Internationalization (BCP 47 + ICU Placeholders)

Cadence uses standard BCP 47 language tags synced directly to <html lang="..."> and supports automatic browser language detection (auto):

  • Supported Locales: English (en), Spanish (es), Japanese (ja), Indonesian (id), German (de), and French (fr).
  • Shared Type-Safe Catalogs: Translation strings live in shared/i18n/locales/ and are validated for 100% key parity by bun test tests/i18n.test.ts.
