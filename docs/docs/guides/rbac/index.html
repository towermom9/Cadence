Role-Based Access & Domains

Manage per-server role permissions across 4 cascading tiers and configure Cadence's public domain live under System Settings.

4-Tier Permission Matrix

Tier Who Qualifies Capabilities
Tier 1 · User Everyone by default, or selected Basic Access Roles Search, /play, /playnext, /playnow, view queue/lyrics/related, personal playlists/likes/pins, remove own tracks
Tier 2 · DJ Members with DJ Role, or alone in VC with bot Skip, back, seek, volume, loop, shuffle, autoplay, DSP filters, queue reordering/clearing, stop/disconnect
Tier 3 · Admin Custom Admin Roles or Discord Manage Server / Admin Live auto-saving Settings -> Server tab and /settings commands
Tier 4 · Owner Server Owner or Bot Owner Settings -> System tab: domain management, runtime & Lavalink diagnostics, redacted debug logs

Changing Public Domain in System Settings

Tier 4 Owners can change Cadence's public URL (for example when moving from http://localhost:8000 to https://music.example.com) directly inside Settings -> System -> Public Domain & Dashboard URL without restarting the container or editing SQLite manually.

  1. Enter your new base URL (or click Use Current URL to fill the browser's current origin).
  2. Click Save Domain to persist to SQLite and apply it live across Discord OAuth2 redirects, session cookie security flags, and embed links.
  3. Copy the updated OAuth2 Redirect URI (<domain>/api/auth/callback) and register it under Discord Developer Portal -> OAuth2 -> General -> Redirects.
