Getting Started

Get Cadence up and running with Docker Compose and connect your Discord server in just a few minutes.

What is Cadence?

Cadence combines a discord.js v14 music bot, a Hono REST + WebSocket API server, a React 19 YouTube Music inspired web dashboard, and an embedded bun:sqlite database into a single lightweight process paired with a self-contained Lavalink v4 audio node.

Single-Process Design
Unlike multi-tier setups requiring MongoDB or external IPC bridges, all settings, playlists, pins, play history, and sessions persist directly inside DATA_DIR/cadence.sqlite.

Prerequisites

  • Docker and Docker Compose v2+ (recommended for hosting)
  • Or Bun v1.2+ + Docker (for local bare-metal development)
  • A Discord Application with a Bot Token, Client ID, and Client Secret

Quick Launch with Docker

Start Cadence using the pre-built GHCR images:

git clone https://github.com/towermom9/Cadence.git
cd Cadence
docker compose up -d
Guided Setup Wizard
You do not need to edit any .env file manually. Open http://localhost:8000 (or http://localhost:8686 in the VPS Compose template) to walk through the 4-step Web Onboarding Wizard.
