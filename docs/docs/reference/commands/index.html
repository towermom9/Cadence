Commands & Shortcuts

Complete reference for all 23 Discord slash commands, customizable prefix commands, and web dashboard keyboard shortcuts.

Discord Slash Commands

Command Options Description
/play query, source Queue a song or playlist with autocomplete (plays next if Default Play Next is enabled)
/playnext query, source Queue a song or playlist right after the currently playing track
/playnow query, source Insert track at the front of the queue and play immediately
/search query, source Pick from top 10 interactive search results
/pause, /resume, /skip, /back, /seek amount, seconds Standard playback transport controls
/stop, /volume, /loop, /shuffle percent, mode DJ playback, loop mode (off | track | queue), and disconnect controls
/autoplay, /filter preset Toggle Smart Autoplay or apply 9 DSP presets (bassboost, nightcore, vaporwave, 8d, etc.)
/queue, /nowplaying, /lyrics - View queue, post Music Controller card, or fetch lyrics
/remove, /clear position Remove a queued track or clear upcoming manual queue
/playlist list | create | add | play | delete Manage and play your saved personal playlists
/settings view | volume | 247 | dj | duplicates | prefix | emptyvc | playnext Configure server settings (Tier 3 Admin)
/dashboard, /help, /ping - Open web dashboard, command help, and latency check

Text Prefix Commands

Using the configurable server prefix (default ?):

  • ?play <query> / ?p <query>
  • ?playnext <query> / ?pn <query>
  • ?skip / ?s, ?pause, ?resume, ?stop / ?leave
  • ?queue / ?q, ?np / ?nowplaying

Web Dashboard Keyboard Shortcuts

Press ? (Shift + /) anywhere outside input fields to open the shortcut overlay:

  • Space - Play / Pause
  • n / Shift + N - Skip to next track
  • k / Shift + P - Previous / restart track
  • Left / Right (or j / l) - Seek backward / forward
  • = / - / m - Volume up / down / Mute
  • s / r / + - Shuffle / Repeat mode / Toggle Like
  • g h, g e, g l, g , - Jump to Home, Explore, Library, or Settings
