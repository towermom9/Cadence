Commands & Shortcuts

Complete reference for all 35 Discord slash commands, customizable prefix commands, and web dashboard keyboard shortcuts.

Playback, Effects & Queue Slash Commands

Command Options Description
/play query, source Queue a song or playlist with autocomplete (plays next if Default Play Next is enabled)
/playnext query, source Queue a song or playlist right after the currently playing track
/playnow query, source Insert track at the front of the queue and play immediately
/search query, source Pick from top 10 interactive search results
/connect - Connect Cadence to your current voice channel
/pause, /resume, /stop - Pause, resume, or stop and disconnect from voice
/skip, /skipto, /back, /replay amount, position Skip forward, jump directly to a queue slot, go back, or restart the current track
/seek, /forward, /rewind seconds Jump to a timestamp or seek forward/backward (default 10s)
/volume, /loop, /shuffle, /autoplay percent, mode Volume control, loop mode (off | track | queue), shuffle, and Smart Autoplay toggle
/move, /swap, /remove, /clear from/to, first/second, position Reorder, swap, remove a track, or clear upcoming manual tracks
/filter, /speed, /pitch, /cleareffect preset, value (0.5 - 2.0) Apply DSP presets (bassboost, nightcore, vaporwave, 8d, karaoke, lowpass, tremolo, vibrato), speed/pitch scaling, or reset effects
/queue, /history, /nowplaying, /grab, /lyrics - View queue/history, post the Music Controller card, DM current song details, or fetch lyrics
/dashboard, /help, /ping - Open web dashboard, command help, and Discord/Lavalink latency check

Playlist & Server Subcommands

Command Group Subcommands Description
/playlist list, view, create, add, savequeue, remove, rename, play, delete Full Discord management for personal playlists, including saving the active queue
/settings view, volume, 247, autoplay, dj, duplicates, prefix, emptyvc, playnext, reset Configure or reset server-wide settings (Tier 3 Admin / Owner)

Text Prefix Commands

Using the configurable server prefix (default ?):

  • ?play <query> / ?p <query>, ?playnext <query> / ?pn <query>, ?connect / ?join
  • ?skip / ?s, ?skipto <pos>, ?back / ?prev, ?replay, ?forward [sec] / ?ff, ?rewind [sec] / ?rw
  • ?pause, ?resume, ?stop / ?leave, ?volume <0-100> / ?vol
  • ?loop <off|track|queue>, ?shuffle, ?autoplay, ?move <from> <to> / ?mv, ?swap <a> <b>, ?clear
  • ?cleareffect / ?resetfilter, ?queue / ?q, ?history, ?grab, ?np / ?nowplaying

Web Dashboard Keyboard Shortcuts

Press ? (Shift + /) anywhere outside input fields to open the shortcut overlay:

  • Space - Play / Pause
  • n / Shift + N - Skip to next track
  • k / Shift + P - Previous / restart track
  • Left / Right (or j / l) - Seek backward / forward
  • = / - / m - Volume up / down / Mute
  • s / r / + - Shuffle / Repeat mode / Toggle Like
  • g h, g e, g l, g , - Jump to Home, Explore, Library, or Settings
