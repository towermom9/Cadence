Troubleshooting & FAQ

Quick fixes for slash command caching, Lavalink search issues, OAuth2 domain changes, and SQLite backups.

`/playnext` or New Slash Commands Missing in Discord

  1. Ensure the running Cadence bot container/process has been restarted with the latest build so registerSlashCommands() pushes all 23 global commands.
  2. Press Ctrl + R (Cmd + R on macOS) in your Discord desktop client to reload Discord's command cache.
  3. While Discord refreshes global commands, prefix commands such as ?playnext / ?pn continue working immediately.

Lavalink YouTube Search Returns No Tracks

  • Verify your Lavalink service runs ghcr.io/towermom9/cadence-lavalink:latest alongside yt-cipher.
  • Check Settings -> System (Tier 4 Owner) to confirm Audio Engine (Lavalink) shows Online with youtube-plugin, lavasrc-plugin, and lavalyrics-plugin loaded.

OAuth2 Login Fails After Changing Domain

When moving Cadence to a new hostname or HTTPS domain:

  1. Update the base URL in Settings -> System -> Public Domain & Dashboard URL.
  2. Copy the updated Redirect URI (https://your-domain/api/auth/callback) and paste it into Discord Developer Portal -> OAuth2 -> General -> Redirects.

Backing Up Cadence Data

All runtime credentials, sessions, playlists, pins, play history, and server settings live in DATA_DIR/cadence.sqlite. Stop the container cleanly and back up the entire data/ directory before major host migrations.
