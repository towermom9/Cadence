Troubleshooting & FAQ

Common questions and practical fixes for voice audio, YouTube rate limits, reverse proxies, permissions, and backups.

Bot Connects to Voice Channel But Plays No Audio

  • Check Audio Engine status: Open Settings -> System (Server/Bot Owner) and verify Audio Engine (Lavalink) reads Online. If it is offline, ensure the lavalink container is running and LAVALINK_HOST / LAVALINK_PASSWORD match.
  • Check Discord Voice Permissions: Confirm Cadence has Connect and Speak permissions in that specific voice channel (and Stage Moderator permission if using a Stage Channel).
  • Check Volume & Mute: Verify Cadence is not server-muted in Discord and server volume is above 0%.

YouTube Search or Playback Fails ("Sign in" / "AllClientsFailed")

Datacenter VPS IP addresses are sometimes rate-limited or flagged for bot verification by YouTube:

  • Ensure the cadence-yt-cipher sidecar container is running alongside ghcr.io/towermom9/cadence-lavalink:latest.
  • If YouTube still blocks anonymous requests on your VPS IP, enable OAuth2 for Lavalink by setting YT_OAUTH_ENABLED=true and YT_OAUTH_REFRESH_TOKEN=... in your Compose environment, or switch your default search provider to Spotify / SoundCloud in Settings -> Playback.

Dashboard Shows Disconnected / OAuth2 Redirect Error Behind Reverse Proxy

  • WebSocket Upgrades: Cadence streams real-time playback state over /ws. Make sure your reverse proxy (Nginx, Caddy, Traefik, Cloudflare) forwards Upgrade and Connection headers.
  • OAuth2 Callback URL: Under Settings -> System -> Public Domain & Dashboard URL, verify the saved URL matches your browser URL (including https://), and copy the generated .../api/auth/callback URI into Discord Developer Portal -> OAuth2 -> General -> Redirects.

Members Cannot See Server Settings or Use DJ Controls

  • Ensure Server Members Intent is enabled in the Discord Developer Portal so Cadence can read member roles accurately.
  • Tier 2 (DJ): Listeners alone in a voice channel receive automatic DJ controls; in multi-listener rooms, assign a **DJ Role** in Settings -> Server.
  • Tier 3 (Admin): Requires Discord Manage Server, Administrator, or a role explicitly added under **Tier 3 · Admin** in Settings -> Server.

How Do I Back Up and Migrate Cadence?

All onboarding credentials, sessions, user playlists, Liked Music, Listen Again pins, play history, and server settings are stored inside DATA_DIR/cadence.sqlite (./data/cadence.sqlite by default). Stop the cadence container, copy the entire data/ folder to your new host, and start Compose again.
