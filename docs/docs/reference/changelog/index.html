Changelog

Complete release history for Cadence from v0.0.0 through the latest release.

v0.1.9 Latest 2026-11-26

  • Grouped playlist playback in Listen again on the Home dashboard so played playlists render as single playlist cards instead of individual tracks.
  • Added Max Play History per-server auto-pruning slider under Settings -> Server and /settings maxhistory (0 = Unlimited, up to 10,000 tracks).
  • Added configurable Stuck-Track Recovery Timeout (5s - 60s, default 20s) under Settings -> System, automatic stalled-track recovery in Lavalink, and raised Lavalink audio buffers.
  • Fixed audio stuttering while dragging volume sliders with a 150ms frontend throttle and >= 120ms coalesced Lavalink volume RPC loop, plus added inline typeable numeric inputs to all sliders via <NumericSlider />.
  • Removed the redundant Settings shortcut inside the TopBar Play on Server popover and consolidated Pause When Voice Channel is Empty strictly inside Settings -> Server.
  • Added collapsible Advanced · Custom Colors (Accent, Canvas, Surface hex pickers + WCAG contrast check) in Appearance, a new Accessibility settings tab (High Contrast, Reduce Motion, 90%-130% Text Scale, Enhanced Focus Rings, 44px Touch Targets, Screen Reader Announcements, Skip Link), and BCP 47 i18n across en, es, ja, id, de, and fr.
  • Expanded isolated bun test coverage with i18n parity tests, WCAG/theme math tests, and mocked Discord slash-command & 4-tier RBAC tests (tests/bot.test.ts).

v0.1.8 2026-11-26

  • Fixed web player bar and mobile Now Playing controls remaining greyed out briefly after a track starts before Lavalink's first heartbeat arrives.
  • Expanded Discord command parity to 35 global slash commands: added /connect, /replay, /skipto, /forward, /rewind, /move, /swap, /history, /grab, /speed, /pitch, /cleareffect, plus new subcommands for /playlist (view, remove, rename, savequeue) and /settings (autoplay, reset) with matching prefix aliases.
  • Updated scrollbars in both the web dashboard and docs site to adapt dynamically to the active dark/light/AMOLED theme.
  • Fixed Cadence logo rendering on nested documentation pages, added System/Dark/Light theme switcher, optimized docs mobile layout & drawer, upgraded search to full-content indexing with highlights, refreshed FAQ, and added this full Changelog.

v0.1.7 2026-11-26

  • Moved documentation from GitHub Wiki into a unified multi-page GitHub Pages site using Cadence's layered logo assets.
  • Added live Public Domain & Dashboard URL configuration under Settings -> System (POST /api/system/domain) with copyable Discord OAuth2 Redirect URI.
  • Added automatic Play on Server switching whenever a logged-in user joins or switches voice channels in Discord.

v0.1.6 2026-11-26

  • Styled Discord empty-VC pause, resume, and disconnect announcements as Music Controller embeds.
  • Converted Server Settings to instant/debounced auto-save and redesigned the Text Command Prefix input into a clean card row.
  • Added repository links in the dashboard footer, cleaned up .gitignore, and expanded AGENTS.md and CONTRIBUTING.md.

v0.1.5 2026-11-26

  • Added Empty Voice Channel Auto-Pause, Auto-Resume, configurable play-on-empty duration slider (0s - 5m), extended Auto-Disconnect slider (Never, 5m - 2h), and Ignore Deafened Listeners toggle.
  • Added /playnext (?playnext / ?pn) and a server-wide Default to Play Next toggle.
  • Added SQLite-paginated Library History with grouped playlist runs, Queue Loop history deduplication, automatic Discord reply cleanup, drag-and-drop boundary fixes, bun test suite, and .githooks/pre-commit.

v0.1.4 2026-11-23

  • Added repository contributor and agent guidelines (AGENTS.md, CONTRIBUTING.md) and documented Empty VC automation.

v0.1.2 2026-11-23

  • Expanded queue timeline history to unlimited played tracks with full queue management.
  • Rebuilt Explore with per-platform interactive search catalogs, fallback recommendations, "View more" pagination, and right-click history entry removal.

v0.1.1 2026-11-23

  • Fixed Queue Loop wrapping past manual tracks so Autoplay tracks are ignored, added bottom queue drop zone, source labels in queue rows, and resilient artwork auto-retries.

v0.0.18 - v0.0.19 2026-11-23

  • Switched to a self-contained cadence-lavalink Docker image that resolves and pre-bundles the latest youtube-plugin, LavaSrc, and LavaLyrics JARs at build time for fast cold starts and reliable bind mounts.
  • Updated README.md with copy-pasteable GHCR Docker Compose templates.

v0.0.16 - v0.0.17 2026-11-23

  • Replaced DM OTP verification with 4-tier cascading Discord Role-Based Access Control (User, DJ, Admin, Server/Bot Owner).
  • Added non-interrupting drag-and-drop for the currently playing track across past and upcoming timeline positions.
  • Added GitHub Actions workflow to build and publish multi-platform GHCR images for cadence and cadence-lavalink.

v0.0.15 2026-11-23

  • Introduced the interactive Discord VC Music Controller embed, perceptual x^1.6 volume curve with instant throttling, /help, /playnow, autocomplete suggestions, and System Debug Logs with automatic PII/token redaction.

v0.0.1 - v0.0.14 2026-11-21 - 2026-11-22

  • Built the YouTube Music inspired React 19 + Tailwind CSS v4 dashboard with real-time 60fps progress interpolation, mobile PWA shell, Listen Again pins, Daily Recommendations, Artist pages, synced ELRC/LRC lyrics click-to-seek, 7 Autoplay moods, Liked Music, playlist import/sync/sorting, dynamic logo/favicon accent themes, and AMOLED surfaces.
  • Added the 4-step Web Onboarding Wizard with live Discord Bot Token & Intent verification, YouTube playback/artwork proxy fixes, and initial Lavalink v4 YouTube plugin integration.

v0.0.0 2026-11-21

  • Initial commit: unified TypeScript, Bun, Hono, discord.js v14, lavalink-client, and bun:sqlite architecture paired with Dockerized Lavalink v4.
