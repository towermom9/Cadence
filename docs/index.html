All-in-One Discord Music Bot & Live Web Dashboard

Cadence unifies a feature-rich Discord music bot, Discord OAuth2 WebSocket API, YouTube Music style React 19 dashboard, and embedded SQLite database into a single lightweight process.

Quick Start with Docker Read the Wiki View on GitHub

Built for Real-Time Listening

Zero external database required - one container for Cadence, paired with pre-bundled Lavalink v4.

YouTube Music Style Dashboard

60fps progress interpolation, AMOLED dark mode, 10 dynamic accent themes, Up Next / Lyrics / Related tabs, right-click context menus, and mobile PWA navigation.

Timeline Queue & Drag-and-Drop

Inspect past tracks, current track, manual queue, and Autoplay suggestions in one timeline. Reorder the currently playing track without interrupting audio.

Smart Autoplay & Synced Lyrics

7 Autoplay moods powered by listener history, liked music, and YouTube Music mixes, plus synced LRC/ELRC lyrics with click-to-seek and auto-scroll.

Empty VC Auto-Pause & Resume

Pause playback after a configurable delay (0s to 5m) when listeners leave, optionally ignoring deafened members, and automatically resume when someone joins back.

4-Tier Role-Based Access

Cascading Discord permissions across User, DJ, Admin, and Server/Bot Owner tiers with automatic system log redaction.

Pre-Bundled Lavalink v4

Self-contained ghcr.io/towermom9/cadence-lavalink image with pre-bundled YouTube, LavaSrc, and LavaLyrics plugins and automatic startup updates.

Quick Start (Docker Compose)

Deploy the pre-built GHCR images and finish configuration in the 4-step Web Onboarding Wizard. 

git clone https://github.com/towermom9/Cadence.git
cd Cadence
docker compose up -d

Open http://localhost:8000 (or port 8686 in the VPS Compose template), enter your Discord Bot Token and OAuth2 credentials in the wizard, and start playing. See the Installation Guide in the Wiki for full reverse-proxy and VPS examples.

Key Discord Commands

23 global slash commands plus customizable text prefix commands (default ?).

Command Prefix Alias Description
/play <query> [source] ?play, ?p Queue a track or playlist with autocomplete (respects Default Play Next setting).
/playnext <query> [source] ?playnext, ?pn Queue a track or playlist right after the currently playing song.
/playnow <query> [source] - Insert a track at the front of the queue and play it immediately.
/pause, /resume, /skip, /back ?pause, ?resume, ?s Control playback in the active voice channel.
/volume, /loop, /shuffle, /filter - DJ / Admin audio and queue controls (9 DSP filter presets).
/settings <subcommand> - Configure volume, 24/7 mode, prefix, DJ role, empty VC pause/disconnect, and Play Next default.
/playlist, /queue, /lyrics, /dashboard ?q, ?np Manage personal playlists, inspect the queue, view lyrics, or open the web controller.
